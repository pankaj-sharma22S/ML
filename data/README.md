# AMEA Sample Datasets

This directory contains version-controlled benchmark and demo datasets used for automated testing and demonstrations.

## Included Datasets:
- `sample_churn.csv`: 150-row tabular binary classification dataset with numerical features (`f1, f2, f3, f4`) and binary target (`churn`).

---
*Note: Large, proprietary, or temporary user datasets are excluded via `.gitignore` to prevent accidental commits.*
